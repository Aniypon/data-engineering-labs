# Домашнее задание 9: ClickHouse - ReplacingMergeTree и управление партициями

## Описание

Домашнее задание по работе с ClickHouse, демонстрирующее:
- Создание таблиц с движком ReplacingMergeTree
- Партиционирование по минутам
- Работу с дубликатами данных
- Перенос партиций между таблицами

## Структура задания

### 1. Создание таблиц
- `events_main` - основная таблица с ReplacingMergeTree
- `events_archive` - архивная таблица с аналогичной структурой
- Партиционирование по минутам через `toYYYYMMDDhhmmss(event_time)`

### 2. Заполнение данными
- Данные в 3 разных партициях (разные минуты)
- Добавление дубликатов для демонстрации ReplacingMergeTree
- Минимум 6 записей в основной таблице

### 3. Перенос партиций
- Копирование партиций из основной таблицы в архивную через `ATTACH PARTITION FROM`
- Удаление перенесенных партиций из основной таблицы через `DROP PARTITION`

### 4. Проверочные запросы
- Просмотр партиций до и после переноса
- Подсчет записей в каждой таблице
- Демонстрация работы дедупликации ReplacingMergeTree

## Файлы

- `homework9_clickhouse.sql` - основной SQL скрипт с выполнением задания

## Запуск

1. Запустите ClickHouse (например, через Docker)
2. Выполните команды из файла `homework9_clickhouse.sql` последовательно
3. Анализируйте результаты выполнения проверочных запросов

## Ключевые особенности

- **ReplacingMergeTree**: автоматически заменяет дубликаты при слиянии партиций
- **Партиционирование**: разделение данных по минутам для эффективного управления
- **ATTACH/DROP PARTITION**: эффективный способ переноса больших объемов данных между таблицами
- **FINAL**: принудительное применение дедупликации при чтении данных
