# Описание SQL запросов

## Запрос 1: Список всех товаров с их категориями
Этот запрос выводит полный список всех товаров в базе данных с информацией о категориях, к которым они относятся. Запрос объединяет таблицы products и categories с помощью JOIN, что позволяет отобразить названия категорий вместо просто их идентификаторов. Результаты сортируются по ID товара.

## Запрос 2: Поиск товаров по ценовому диапазону
Данный запрос демонстрирует фильтрацию товаров по цене в определенном диапазоне (от 50,000 до 100,000). Это типичный сценарий для интернет-магазина, где пользователи могут фильтровать товары по ценовому диапазону. Запрос возвращает название товара, цену и количество на складе, сортируя результаты по возрастанию цены.

## Запрос 3: Детальная информация о заказе
Этот запрос предоставляет подробную информацию о конкретном заказе (ID заказа = 2), соединяя несколько таблиц: orders, users, order_items и products. Запрос показывает номер заказа, дату создания, статус, информацию о пользователе, а также все товары, включенные в заказ, с их количеством и ценой. Такой запрос может использоваться для отображения детальной страницы заказа в админ-панели или в личном кабинете пользователя.

## Запрос 4: Список пользователей и их избранных товаров
Этот запрос демонстрирует связь "многие ко многим" между пользователями и избранными товарами. Он соединяет таблицы users, favorites и products, чтобы показать, какие товары каждый пользователь добавил в избранное. Результаты сортируются по имени пользователя и названию товара, что упрощает анализ предпочтений пользователей.

## Запрос 5: Товары в корзине пользователя
Запрос показывает содержимое корзины конкретного пользователя (ID пользователя = 2). Он объединяет таблицы users, cart, cart_items и products для получения полной информации о товарах в корзине, включая наименование товара, количество, цену за единицу и общую стоимость (подсчитанную как произведение цены и количества). Такой запрос необходим для отображения страницы корзины пользователя в интернет-магазине.

## Запрос 6: Статистика по категориям товаров
Этот запрос представляет собой аналитический отчет по категориям товаров. Он использует агрегирующие функции (COUNT, SUM, MIN, MAX, AVG) для расчета статистических показателей по каждой категории: общее количество товаров, общее количество на складе, минимальная, максимальная и средняя цена. Запрос использует LEFT JOIN, чтобы включить категории, которые могут не иметь связанных с ними товаров. Результаты сортируются по количеству товаров в категории в порядке убывания. Такой отчет может быть полезен для анализа ассортимента магазина и принятия решений по управлению запасами и ценообразованию.
