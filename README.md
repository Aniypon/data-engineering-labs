# Data Engineering: проектирование и эксплуатация хранилищ

Практикум курса «Data Engineering» (программа «Дизайн и разработка информационных продуктов»,
НИУ ВШЭ × Центральный университет).

Сквозная линия — одна предметная область (интернет-магазин), которая проходит через все задания:
сначала проектируется схема, потом наполняется и оптимизируется, потом разносится по
специализированным хранилищам под конкретные паттерны нагрузки.

## Что здесь показано

**PostgreSQL:** проектирование схемы, индексы и планы запросов, уровни изоляции и аномалии,
декларативное партиционирование.
**Не только PostgreSQL:** MongoDB, Redis, ClickHouse, Cassandra — с обоснованием, почему под
конкретную задачу выбрано именно это хранилище.
**Инфраструктура:** каждое задание поднимается через свой `docker-compose.yml`.

## Как запустить

Нужен только Docker. Каждое задание — со своим compose-файлом:

```bash
cd дз10
docker compose up -d
docker exec -it cassandra-hw10 cqlsh -f /schema.cql
```

Точные команды, порты и учётные данные — в `README.md` внутри задания.

> Пароли в `docker-compose.yml` — локальные значения для одноразовых учебных контейнеров,
> не секреты.
