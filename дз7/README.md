# MongoDB Домашнее задание 7

### 1. Запуск MongoDB в Docker
```bash
# Запуск контейнера через docker-compose
docker-compose up -d
```

### 2. Запуск скрипта с запросами
```bash
# Запуск скрипта с созданием базы данных, коллекций и запросами
docker exec -it mongodb mongosh -u admin -p secret --file mongodb_setup.js
```

## Структура данных

База данных `shop` состоит из двух коллекций:

### Коллекция products
```json
{
  "name": "iPhone 15",
  "price": 80000,
  "quantity": 10,
  "description": "Новый iPhone с чипом A17 Pro",
  "category": "Смартфоны"
}
```

### Коллекция orders
```json
{
  "customer_email": "ivan@mail.ru",
  "product_name": "iPhone 15",
  "quantity": 2,
  "total_price": 160000,
  "order_date": new Date("2023-12-15")
}
```

## Реализованные запросы

### Простые запросы
- Найти все товары дороже 50000 рублей
- Обновить цену товара по названию
- Удалить товар с количеством 0

### Агрегации
- Подсчет средней цены товаров в каждой категории
- Топ-3 самых дорогих товара с их категориями
- Общая стоимость всех товаров на складе (цена × количество)
- Категории, где средняя цена товаров больше 30000 рублей
- Сумма всех заказов
- Сумма всех заказов по customer_email с сортировкой по убыванию общей суммы
- Топ-3 самых продаваемых товара
